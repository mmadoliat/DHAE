Forecasting curves together with the measurements that come with them

Neural autoencoders learn a small latent state from a daily curve and its scalar companions; a vector autoregression moves that state forward; a smooth decoder turns it back into a forecast curve, and, in the variational version, into a forecast distribution.

One pipeline, two papers

Each day t gives a curve sampled on a grid and, for hybrid data, a vector of scalar measurements such as weather. A fixed B-spline layer turns the curve into features; a shared encoder maps features and scalars to a latent state; a VAR forecasts the state; a shared decoder returns B-spline coefficients and the scalar part. Because the decoder works through a basis, every forecast is a smooth function.

The two papers differ in one place, the latent state. In HAE it is a point; in VHAE the encoder returns a Gaussian distribution for it, so forecasts carry uncertainty about where the latent state is as well as about where it goes next.

HAE: hybrid autoencoders with shared temporal latent dynamicsnear submission

Pourmoshir, Haghbin and Maadooliat. The functional autoencoder (FAE) replaces FPCA scores by nonlinear latent coordinates; the hybrid autoencoder (HAE) gives the curve and the scalar measurements one shared latent state, one VAR and one decoder. The linear benchmark is hybrid PCA (HPCA), which is HAE with identity activations.

On the Metro Interstate Traffic Volume data (1,214 complete days, 24 hourly values and 49 weather, holiday and calendar variables per day) HAE + VAR reduces the 7-day forecast MSE relative to HPCA + VAR by 34% for the traffic curves and 17% for the scalar measurements in our rerun of the paper's configuration.

A reproducibility audit of the HAE results is in REPRODUCIBILITY_AUDIT.md. The Metro comparison with HPCA reproduces; the simulation tables currently do not reproduce from the repository code.

VHAE: variational hybrid autoencoders for probabilistic forecastingdraft

The encoder of the HAE is replaced by a Gaussian posterior trained with a β-weighted evidence lower bound; the VAR is fitted to the posterior means. A forecast draw starts from a posterior draw of the latest latent states, adds VAR innovations, decodes, and adds observation noise estimated from reconstruction residuals. HAE and HPCA get the same treatment without the posterior draws, so the comparison isolates the representation.

Reproduce

git clone https://github.com/mmadoliat/DHAE.git && cd DHAE
conda env create -f environment.yml && conda activate py39
python HAE/run_metro.py          # HAE paper, Metro table and figure
python HAE/run_fertility.py      # HAE paper, fertility application
python VHAE/run_metro.py         # VHAE paper, Metro table and figure
python VHAE/run_fertility.py     # VHAE paper, fertility table and figure
python docs/build_site.py        # rebuild this page from the result files

Each script writes its numbers and the software versions to a results folder. HAE/README and VHAE/README map every table and figure to the script that produces it.
